## 📋 &nbsp; PROJECT OVERVIEW

**EZ Task** is a simple task management web application designed to make organizing everyday tasks quick and straightforward.

The project focuses on a clean interface and simple interactions without requiring a complicated setup or backend.

### ✨ Core Features

- 📋 **Task Management** — Create and manage tasks
- ✅ **Task Completion** — Keep track of completed work
- 🎯 **Simple Workflow** — Focus on the tasks that matter
- 🎨 **Clean Interface** — Minimal and easy-to-use design
- ⚡ **Lightweight** — Runs directly in the browser
- 📱 **Responsive Design** — Designed to work across different screen sizes

## 🚀 &nbsp; QUICK START

### 📦 Clone the Repository

```bash
git clone https://github.com/Azu-rial/EZ-Task.git
cd EZ-Task
```

### 🌐 Run the Application

Simply open:

```text
index.html
```

in your browser.

No server or additional dependencies are required.

## 🎨 &nbsp; DESIGN

EZ Task was built around a simple idea:

> **Task management shouldn't feel complicated.**

The interface keeps the experience focused on the tasks themselves while using a clean visual layout and lightweight frontend code.
